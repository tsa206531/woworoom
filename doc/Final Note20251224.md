# 窩窩家居 (WOWOROOM) 網頁技術描述報告

## 一、簡單描述

窩窩家居 (WOWOROOM) 是一個整合家具電商前台與訂單管理後台的網頁應用程式。該專案採用傳統的網頁開發架構（Vanilla JS），透過簡單直觀的介面，提供使用者瀏覽商品、加入購物車及下單的功能，並為管理者提供營收分析圖表與訂單管理機制。整體開發方向聚焦於前後端的分離協作，利用第三方 API 服務實現動態資料存取。

## 二、功能描述

### 1. 前台購物介面 (index.html / index.js)

- **商品瀏覽與篩選**：從 API 取得產品清單，並提供分類篩選功能（如床架、收納、窗簾）。
- **購物車管理**：使用者可將商品加入購物車，進行單項刪除或清空所有品項。
- **訂單提交**：提供完整的預訂資料表單，包含表單驗證機制，並將訂單資訊上傳至雲端。
- **動態互動效果**：包含好評推薦牆的滑鼠抓取拖曳效果與選單切換動畫。

### 2. 後台管理系統 (admin.html / admin.js)

- **營收數據視覺化**：整合訂單資料，以圓餅圖呈現各產品的營收比重。
- **訂單狀態調整**：管理者可切換訂單的處理狀態（已處理/未處理）。
- **訂單刪除機制**：支援刪除單筆訂單或清除後台所有訂單記錄。

## 三、完整技術描述

### 1. 前端技術 (Frontend)

- **基礎架構**：使用語義化 **HTML5** 及 **CSS3**。CSS 部分包含自定義的響應式設計，確保在不同設備上的呈現效果。
- **核心邏輯**：採用 **原生 JavaScript (ES6+)** 編寫，未使用大型框架（如 Vue 或 React），展現了強健的 DOM 操作能力。
- **資料通訊**：使用 **Axios** 函式庫處理非同步 HTTP 請求 (GET, POST, DELETE, PUT)，與後端 API 進行溝通。
- **資料視覺化**：後台報表採用 **D3.js** 與 **C3.js**，將枯燥的訂單數據轉化為直觀的互動式圓餅圖 (Pie Chart)。
- **外部資源**：
  - **Google Fonts**：Noto Sans 字體提升視覺質感。
  - **Material Icons** & **Font Awesome**：提供直觀的圖示系統。

### 2. 後端技術與 API 設計 (Backend & API)

- **API 服務**：接入 **Hexschool LiveJS API**，這是一個成熟的電商 API 服務，提供完整的產品 (Product)、購物車 (Cart) 及訂單 (Order) 資源。
- **身份驗證**：透過 `Authorization` Header 攜帶 API Token 進行管理權限校驗。

### 3. 資料處理方式

- **非同步載入**：網頁初始載入時即觸發 `init()` 函式，透過 Axios 從遠端取得產品與購物車快照。
- **格式化處理**：內建 `toThousand()` 函式處理價格數字的千分位符號，提升閱讀體驗。
- **時間戳記轉換**：後台將 API 回傳的 Unix Timestamp 轉換為可視化的 `YYYY/MM/DD` 格式。

## 四、未來可以改善的方向

1.  **導入現代化框架**：雖然 Vanilla JS 效能優異，但隨著邏輯增加，維護成本會提升。建議遷移至 **Vue 3 (Composition API)** 或 **Nuxt 3**，以元件化思維優化開發。
2.  **表單驗證強化**：目前表單驗證較為基礎。可導入 `validate.js` 或自定義更嚴謹的正規表示式 (Regex)，並提供更即時的 UI 反饋（如欄位紅框提示）。
3.  **安全性提升**：目前的 API Token 直接暴露於前端 JS 檔案中。在生產環境下，建議透過環境變數或後端代理 (Proxy) 來保護敏感資訊。
4.  **效能與 UX 優化**：
    - 導入 **Skeleton Screen (骨架屏)** 替代目前的 SVG Loading 動畫，提升載入感官預期。
    - 實作圖片的 **懶加載 (Lazy Loading)** 以優化首屏加載速度。
